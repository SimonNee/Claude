# C++ STL Practice Exercises

## Overview

This directory contains hands-on STL practice exercises for the user. The user is learning C++ STL and working through exercises at their own pace.

## Current State

- `vector_exercises.cpp` - 10 progressive std::vector exercises (easiest to hardest)
  - Each exercise has a stubbed function with `// YOUR CODE HERE`
  - A test harness at the bottom prints PASS/FAIL for each exercise
  - Compile: `g++ -std=c++17 -o vector_exercises vector_exercises.cpp`
  - Run: `./vector_exercises`

## Workflow

1. The user implements the exercises themselves
2. When they ask for review, read the file and give feedback on their solutions
3. Focus on: correctness, use of STL features, readability, and efficiency
4. After vector exercises are complete, move on to more practical real-world examples using other STL containers and algorithms

## Important

- This is a learning exercise - do NOT solve the exercises for the user
- When reviewing, suggest improvements but explain the reasoning
- The user wants to progress from basic exercises to practical real-world examples
